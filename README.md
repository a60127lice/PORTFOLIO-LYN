# Chang Ya-Lin Portfolio

This is a dependency-free responsive portfolio starter for Chang Ya-Lin, Interior Designer / Spatial Designer, based in Glasgow.

## Preview

Open `index.html` in a browser. The site includes Home, Work, four project case studies, About, CV, and a 404 page.

## Replace the content

- Edit the four files in `projects/` to add each case study.
- Keep project facts explicit: title, type, location, year, role, contribution, process, technical development, final design, captions, and credits.
- Replace the intentional placeholder blocks with supplied images and meaningful alt text.
- Replace `assets/chang-ya-lin-cv.pdf` with the real CV PDF.
- Update `hello@example.com` and the LinkedIn placeholder in the HTML footers.
- Edit `styles.css` for global design tokens only when the visual direction is intentionally changing.

## Verification

Static route/link checks and a 375px browser smoke test pass. Node.js is not available in the current environment, so npm linting, typechecking, production builds, Lighthouse, and automated E2E/accessibility suites remain to be run after Node is installed.
